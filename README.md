# 실시간 포커 분석기

`Start-Poker-Analyzer.cmd`를 더블클릭하면 브라우저에서 실행됩니다.

- 상단의 **로컬 카드**와 **플레이어당 카드(1~7장)**에서 카드 수를 각각 변경할 수 있습니다. 한 핸드에서 합계가 최소 5장이 되어야 분석을 시작합니다. 전체 카드 수가 52장을 넘는 조합은 분석하지 않습니다.
- 카드 형식: `Ah`, `Kd`, `7c`, `10h` (`c` 클로버, `d` 다이아, `h` 하트, `s` 스페이드)
- 빈칸 또는 `?`: 알 수 없는 카드로 처리
- 카드가 모두 공개되어 남은 보드 조합이 작으면 **EXACT** 계산
- 그 외에는 UI를 멈추지 않는 Web Worker 기반 **MONTE CARLO** 시뮬레이션
- 입력 변경 후 180ms 디바운스, 새 변경이 발생하면 이전 Worker는 종료되어 최신 결과만 표시

포트 `8765`가 이미 사용 중이라면 `Start-Poker-Analyzer.cmd`의 `8765`을 사용하지 않는 숫자로 바꿔 주세요.
